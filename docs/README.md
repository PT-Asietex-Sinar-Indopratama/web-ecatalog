# Dokumentasi Web E-Catalog

Dokumentasi ini melengkapi [PRD](./PRD.md) dengan panduan arsitektur, domain,
fitur, dan struktur teknis Web E-Catalog.

## Urutan membaca

1. [PRD](./PRD.md) - tujuan, scope, persona, katalog publik, aset produk,
   request quotation, dan kriteria penerimaan utama.
2. [Architecture](./architecture.md) - struktur teknis, data model, API
   conventions, dan arah maintainability.

## Daftar dokumentasi

| Dokumen                           | Fungsi                                                               |
| --------------------------------- | -------------------------------------------------------------------- |
| [PRD](./PRD.md)                   | Scope produk, katalog publik, aset, inquiry, roadmap, dan acceptance |
| [Architecture](./architecture.md) | Struktur aplikasi, data model, API conventions, dan maintainability  |

Dokumentasi ini tidak menggantikan PRD. Jika terdapat perbedaan scope, PRD dan
keputusan bisnis terbaru menjadi acuan utama.
