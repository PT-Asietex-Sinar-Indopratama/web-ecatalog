# Public Catalog

## Tujuan

Katalog publik membantu visitor menemukan informasi produk tanpa login.

## Daftar produk

Visitor dapat:

- Melihat produk aktif.
- Mencari berdasarkan nama, SKU, material, deskripsi, dan kategori.
- Memfilter satu atau beberapa kategori, termasuk turunan kategori.
- Mengurutkan terbaru, terlama, nama A-Z, atau nama Z-A.
- Menggunakan tampilan grid atau list.
- Berpindah halaman melalui pagination.
- Menggunakan filter pada desktop maupun mobile.

## Detail produk

Detail menampilkan nama, SKU, jalur kategori, material, deskripsi, gambar utama,
status file, dan link download PDF jika tersedia.

Target MVP menambahkan gallery, request quotation, dan link WhatsApp sales.

## Aturan publik

- Login tidak diperlukan.
- Produk nonaktif tidak boleh muncul pada listing maupun detail.
- File PDF hanya ditampilkan jika tersedia dan valid.
- URL detail harus stabil dan mudah dibagikan.
- Metadata halaman harus mendukung SEO; produk nonaktif tidak boleh diindeks.
